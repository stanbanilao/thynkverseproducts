Installation guidance

Choose the approved installation path when it becomes available.

These steps are published for preparation only. All installation actions remain unavailable until the owner approves a verified LIVE release.

01 / STORE

Chrome or Edge store

Click the approved store install button, choose Add, pin Thynkly, open it, enter the link code from your Supervisor, then select Link this PC.

02 / MANUAL

Manual ZIP

Download and unzip the verified package. Open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, select the unzipped folder, pin Thynkly, enter the link code, then select Link this PC.

03 / COMPANY IT

Managed company PCs

IT can force-install the approved store extension through Chrome or Edge policy using Intune or Group Policy after the owner provides the verified store extension ID.

04 / LICENCE

Licence required

Installation alone does not grant access. The company needs an active THYNKLY / LEADGEN licence in Super Control and the user needs a valid Supervisor-issued link code.
