Licence & activation

Downloading does not unlock the product.

When a LIVE installer becomes available, it may be downloaded and installed on an approved device. The application remains unusable until the customer has a valid Thynkverse licence or entitlement and successfully activates through Super Control.

Release control

Public downloads follow the release gates.

01

DEV / BUILD

The product is built and packaged privately. Source code is never the customer download.

02

TEST → VERIFY

The product is validated in its TEST environment before any customer-facing promotion.

03

DEMO / PILOT → VERIFY

The approved package is validated again in the pilot stage.

04

LIVE

Only after LIVE approval does the Download button become active on this page.
